# 百闻牌桌宠（BwpDesktopPet）

把《阴阳师：百闻牌》里的 Spine 立绘放到 Windows 桌面上，做成会动、会冒台词气泡、能陪你干活的桌宠。

- **渲染端**：**在开源桌宠项目 [DeskSpine](https://github.com/ww-rm/DeskSpine)（作者 ww-rm，Apache-2.0）之上做的二次开发**，代码在 `deskspine/`（它保留自己的 git 历史）。上游随仓库带的那三组演示骨骼素材已经从这份分支里删掉了，现在这一层的**仓库**里也不自带任何别家的游戏素材；**GitHub Release 那两个 zip 附件带四只**（2026-11-04 仓库主人裁定：发出去的 release 就是一份百闻牌桌宠）—— 两条轨道都写在「许可与署名」。
- **素材端**：自己写的一条管线 —— 识别、配对、打包、联系表出图、字体覆盖检查，脚本在 `bwp-assets/`。
- **对外的名字**：程序名 `BwpDesktopPet`（exe / 装配 / 安装包产品名），托盘提示和「关于」窗上显示的是**百闻牌桌宠**。

> **先说边界。** 游戏素材（图、语音、骨架）的版权属于网易和对应画师。**两个仓库里都不含素材本体**，也不写怎么从客户端里取；`deskspine/` 那一层原先夹带的上游演示素材（碧蓝航线、明日方舟的角色，版权不在网易也不在我们）同样已删。仓库跟踪的是代码、脚本、文档，加上一批**索引表和清单表**（哪一页、哪一帧、哪几副骨架、语音条目对到哪个 media id）。以前有三份表夹着游戏语音的**转写文本**，2026-11-04 已经从全部历史提交里剔掉了，来龙去脉写在「许可与署名」。
>
> **2026-11-04 仓库主人改了一次裁定：发出去的那份 release 就是一只百闻牌桌宠。** 于是现在是两条并排的轨道 —— **git 那一头照旧 0 字节素材**（跟踪文件和历史里都翻不出骨骼、贴图、语音、那颗衍生图标），**Release 那两个 zip 附件带着**（附件里 `res/` 现场读数：89 个文件、12.8 MiB —— 四副骨架和同名图集、34 张页图与界面件、42 条不知火表情语音、22 条台词池原文、那颗衍生应用图标和番茄钟那颗达摩）。附件里那张《运行前先看.txt》把权利归属和「这一版还没有静音开关」都写在明面上。**没变的那半**：不商用、不卖、素材被要求撤下就撤；把带素材的附件挂上公开 release 是仓库主人自己点头、自己承担的那部分风险。闸为此开了一处**只在产物模式生效**的素材豁免（`res/spine/`、`res/dialog/` 两个前缀放过中文/日语那两条文本线，本机用户名和逐文件字节那两条照查），见「许可与署名」最后一条。

## 现在能干什么

| | |
| --- | --- |
| **宠物本体** | 真 Spine 骨骼动画，贴在一扇分层窗上。**待机 / 警觉 / 攻击 / 施法 / 登场 / 睡觉**这六套动作按骨架上实际有的动画名对号入座（缺哪套就退回同义的那套），表情骨架还会换脸。单击 / 双击 / 滚轮都会触发互动动作（双击和滚轮走的是同一条），**Ctrl+滚轮**换出场的那只，**左键拖动**移动，可以点穿、可以缩放、可以调透明度 |
| **角色名册** | 10 个槽位；配了中文名的是 **不知火、千姬、猫掌柜焕宴、蟹姬** 这四只（托盘「切换角色」那几行就照这张名表渲染，名表里没有的会掉回拼音文件夹名），`ActiveSlot = -1` 是图层模式（几格叠着一起画） |
| **包内素材首启登记** | 只对外发的那两份 zip 附件用：第一次启动程序看一眼自己旁边的 `res\spine`，**同名 `.atlas` 齐的才登记**（最多十格，按目录名序排），写进去的是 V306 / 模式5(BwpHero) / 出场格 0 / PMA 真 / 可见真。**两头都有守卫**：本机已经有配置的整份跳过、一个字节不回来覆盖；压根没这个目录的（自己 clone 建的那份）静默不写文件。链子由 `Program.Main` 那一跳跳进 `BundledRoster.SeedIfFirstRun`，`desk` 第 27 层拿合成假骨架钉规则，打包脚本再拿**附件里那四只真骨骼**跑一遍 |
| **番茄钟** | 右键宠物 → 「番茄钟」开预设小窗：工作 / 休息 / 长休时长、几轮一次长休、到点弹气泡、专注期间不许宠物睡着、自动开始下一段的两个开关。专注时宠物头顶贴一条倒计时数字；跳过不计数、记的是轮内第几段 |
| **台词气泡** | 不知火专属的台词池（22 条游戏原文，只在本机、不入库），按节拍亮 15 秒自己收起、再空 60 秒；名牌大红底烫金，纸是游戏里裁的对话框。**切到别的角色就不弹** —— 台词是谁的才在谁出场时念 |
| **今日天气** | 右键宠物 → 「查看天气」：按 IP 定位、中文城名、当前读数 + 今日高低 + 风，底下那句建议跟着屏幕上是谁换腔（不知火用她的口吻，别的角色退回中性）。这是**本项目唯一主动联网**的功能：四个端点全 HTTPS、一个 key 都不要、断了也只是卡片上多一行「读不到天气 + 为什么」 |
| **整点报时** | 到点弹一颗气泡，图标和番茄钟共用同一张红达摩 |
| **托盘菜单** | 上游那份菜单里插了四项：**切换角色 / 番茄钟 / 查看天气 / 台词**，底下还是原来的 设置(&S) / 关于(&A) / 退出(&X)，上游的显示精灵、壁纸模式、鼠标穿透、一键全屏、窗口复位、启动 SpineTool 都没动 |
| **配置什么时候落盘** | 设置窗点「应用 / 确认」、托盘那几个开关、切角色、台词开关都**当场写盘**；「退出」再写一次；另外有个 5 分钟一拍的定时器，把拖动位置、缩放这类没走按钮的改动收进去。**硬杀进程丢的就是最后那一拍** |
| **开机自启** | 设置窗那个勾写 `HKCU\...\Run` |
| **图标** | 应用图标是不知火的白+红两色剪影徽章。那张是版权衍生件，**不进仓库**（`.gitignore` 挡着，重生成命令写在注释里）；没有它的时候 exe 退回上游那颗、托盘和标题栏静默退回上游 resx 里的占位，不弹窗 |

上游那几样功能也都在：动画导出（走 SpineTool）、性能监视窗、壁纸模式、一键全屏、窗口复位。

**界面长什么样 —— 这里欠一张图。** 这台机器上桌面抓屏被安全策略挡着，所以所有观感结论（图标认不认得出、小窗挤不挤、那句话对不对味）都还没经过肉眼复验，文档里一律标着 `SKIP`，不假装通过。最靠谱的做法是自己跑起来看一眼，下一节就两条命令。

## 上手

### 需要

- Windows 10/11 + **.NET 8 SDK**（`net8.0-windows` + WinForms；SFML.Net 2.6.0 由 NuGet 自动还原）
- **Python 3**：跑桌宠只需要 `setup_pet.py`，它只用标准库；`out/font_cover.py`（字体覆盖检查）要 `fontTools`；出图标的那几个脚本要 `Pillow` + `numpy`。再往下的素材管线另有 `texture2ddecoder`、`scipy`，语音那条线要 `faster_whisper`（已搁置，不用装）
- **一副 Spine 骨架**（`.skel` + 同名 `.atlas` + 它的页图）。仓库不提供游戏素材 —— 要么你已经有自己解出来的东西，要么随便换一副你自己的 Spine 模型试跑。**这条只约束「从源码建」那一路**：Release 附件里已经带着四只，解压就有宠物，见上面「先说边界」和下面「已知还欠着的」

### 1）建

（`deskspine/` 是第二个仓库，只克隆根仓库拿不到它 —— 见下面「仓库里有什么」。）

```powershell
cd deskspine
dotnet build DeskSpine.sln -c Release -v q --nologo
```

产物在 `deskspine/out/x64/Release/net8.0-windows/win-x64/BwpDesktopPet.exe`（**路径里那个 `win-x64` 别漏**）。

**一定要带 `.sln`**：直接 build `DeskSpine/DeskSpine.csproj` 会绕过 csproj 里的 `BaseOutputPath=$(SolutionDir)out`，产物落进一个没人看的目录，桌面上起的和判据读的都是旧包 —— 这个坑真踩过，现在有一条判据专门盯着它。

### 2）跑起来

先托盘右键**退出**正在运行的那只（开发版和 MSI 装的共用配置目录和同名 Mutex，只能同时跑一个），然后：

```powershell
cd ..\bwp-assets
python setup_pet.py                          # 装默认名册（不知火 / 猫掌柜焕宴 / 千姬 / 蟹姬）
python setup_pet.py D:\models\aaa.skel ...   # 或指定任意若干副骨架，最多 10 格
```

它做三件事：重编译 Release → 把骨架路径写进 `%LOCALAPPDATA%\DeskSpine\config.json` 的槽位名册 → 启动。原配置先备份成 `config.json.bak`。

> 默认名册写的是槽位 0..3，然后把 `SkelPath4..9` 清空。你自己的名册比这四只更长，就把多出来的骨架路径一起当参数给它，否则第 5 只之后会被抹掉。脚本里那份中文名对照和 `PetNames.cs` 是同一套，托盘「切换角色」上不会出现拼音文件名。

不想碰脚本也行：直接双击 `BwpDesktopPet.exe`，托盘右键 → 设置 → 把 `.skel` 的**绝对路径**填进某一行 `SkelPath`，再把出场槽位选成它。

> **新克隆第一次双击会看到「什么都没有」——这是正常的，不是没建起来。** 上游那三组演示骨骼删掉之后，出厂名册就是空的（`Config.cs` 里不再有指向它们的默认值）。这一句是在**一份不带任何本机素材的克隆**上实测的，不是推：两种配置都 `0 个警告 0 个错误`，产物里的 `res/` 只剩上游自己那张 `image/hourlychime.ico`；跑起来进程活着、**不弹错误框**、屏幕上只有**一扇 1000×1000 摆在 (0,0) 的透明窗**，里面没人（测的是 Debug 版，它的数据目录是 `%LOCALAPPDATA%\DeskSpine_d`，碰不到现场那份 Release 配置；测完那份目录已清掉）。往屏幕上加人就是上面那条路：托盘左键双击开设置窗、填 `SkelPath`、点应用。
>
> **Release 附件那一份走的不是这条路。** 包里带着 `res\spine` 那四只，第一次启动程序自己认一遍同名 `.atlas` 齐不齐、把齐的登记进名册（`deskspine/DeskSpine/src/BundledRoster.cs`）。这条链子两头都钉过：`desk` 第 27 层用合成假骨架钉规则（五处 bug 放回去各红一次），打包脚本 `projects/_publish/package_release_zips.py` 再拿**附件里那四只真骨骼**在临时目录跑一遍首启 —— 现读数是「回 4 只」，托盘那四行渲染成 不知火 / 猫掌柜焕宴 / 千姬 / 蟹姬。**已经有配置的人首启整份跳过、一个字节不覆盖**，所以在这台开发机上直接双击附件是看不到那四只冒出来的（本机名册照旧）；「解压完真在桌面上站着」这一步要挪开 `%LOCALAPPDATA%\DeskSpine` 才验得到，本机没挪、也没杀正在跑的那只，**这一条标 SKIP 等肉眼**。

### 3）日常手势

| 手势 | 干什么 |
| --- | --- |
| 左键单击 | 播一条互动动作；宠物正睡着的话，改成播登场把它叫醒 |
| 左键双击 / 滚轮 | 播另一条互动动作（这两个手势走的是同一条） |
| **Ctrl + 滚轮** | 换出场的那只角色（不按 Ctrl 的滚轮是上面那条互动） |
| **左键拖动** | 移动宠物。按下到抬起挪过 4 格才算拖动，不然还是单击；拖动起手换警觉姿态，松手回待机 |
| **右键单击** | 弹功能选择小窗（番茄钟 / 查看天气） |
| 右键拖动 | **不移动宠物**，只给窗口描一圈边框，动画和左键拖动一样 |
| 托盘图标**右键** | 近路：切换角色、番茄钟、查看天气、台词、设置、关于、退出 |
| 托盘图标**左键单击** | 弹性能监视窗（贴着任务栏图标那一侧） |
| 托盘图标**左键双击** | 打开设置窗 |

配置在 `%LOCALAPPDATA%\DeskSpine\config.json`。**目录名仍是 `DeskSpine`** —— 见下面「读代码前必知的三个坑」第 3 条，那是裁定不是漏改。

## 改了代码之后怎么自证

四道门 + 一次真启动。头两条是构建，别省 —— 省了跑的就是旧产物：

```powershell
cd bwp-assets
dotnet build ..\deskspine\DeskSpine.sln -c Release -v q --nologo
dotnet build animator-test -c Release -v q --nologo      # 不在那个 sln 里, 漏了这步跑的是旧 exe
.\animator-test\bin\Release\net8.0-windows\bwp-animator-test.exe desk
```

| 跑这个 | 期望看到 | 它在量什么 |
| --- | --- | --- |
| `...bwp-animator-test.exe desk` | 末行 `DESK OK`，**27 层全过**（绿的时候只打 26 行报告 —— 「番茄钟文案」那层出错才出声） | 无头反射 + 真建窗口 + 真喂鼠标事件，把「接线接没接上」逐条钉住：配置段往返、设置窗控件不丢数、番茄钟状态机边界、气泡几何与节拍表、托盘菜单渲染、天气换算表、图标链、名字链、包内素材首启登记那条链 |
| `...exe seed <附件解压目录>\BwpDesktopPet.dll <同目录>\res\spine <一个空目录>` | `SEED OK` + 「回 4 只」+ 托盘那四行读成 不知火 / 猫掌柜焕宴 / 千姬 / 蟹姬 | **只有 release 附件用得着的一把尺**：拿真 dll 装真素材，在临时目录里把首启登记跑一遍（几只 / 路径真在场且就在包里 / 中文名不重样 / 五个值落对 / 第二次首启回 0 且原样）。反射读出的那个临时路径**等于本机 `%LOCALAPPDATA%\DeskSpine\config.json` 就直接拒绝跑** —— 这条尺子不许碰用户的数据。打包脚本出附件前自己喊它，两份各一遍 |
| `....exe pomodoro <绝对路径>\buzhihuo_1127.skel` | `POMODORO OK` | 假时钟快进整一轮：边界换脸、专注期间不许睡、合盖六小时不补出一串番茄、跳过不记数、那两个自动开始开关。**必须给绝对路径**（相对路径按 animator-test 的项目目录解，不是按你的 cwd）。这条要一副真骨架，而骨架不入库 —— 克隆下来没有素材就换成你自己那副 |
| `python out\font_cover.py --check` | `CHECK OK` | 产品界面用到的每一个字（现在 228 个），在系统那支字体里都有真字形（借笔就会在板上开天窗）。它读的是 `C:\Windows\Fonts` 和用户字体目录，标题那支笔是**华文中宋**（随 Office 装）—— 机器上没有它这条就会红，红的是字体不是代码 |
| `...exe weather` | `WEATHER OK` + 板上那四行读数 + 底下那句建议（中性和她那一档各打一份） | **全仓库唯一会出门的一趟**：真 IP 定位 → 中文城名 → 取数。判据那 27 层一次网络都不发，端点活不活着由这条说 |

判据 27 层逐条是什么、钉住什么，写在 [`docs/交接报告.md` 的 §6](docs/交接报告.md)。往上添新判据的纪律是**把对应的 bug 放回去，验它会不会红** —— `bwp-assets/reverse_red_*.py` 就是这么一轮轮跑过来的，抓出来过好几次**不是产品的 bug，而是判据或工具自己的假绿**（图标轮 1 处「整关没跑到终点」被记成「不对」、改名轮 1 处「旁边有没有 exe」、首启登记轮 3 处：空包那棵把自己**抛崩**了、摘图集那棵的期望值**归产品定不归尺子编**、负对照一开始改的是**目录名**而名表读的是**骨架文件名**所以照旧绿；闸那两轮另有「不带 `-z` 会被 `core.quotePath` 藏掉中文文件名」和「闸当时还没进跟踪列表所以咬不到自己」）。记住这四种都不算「绿」：判据自己炸了、判据根本没跑到那一层、判据量得太松所以红不起来、判据的期望值是我替产品编的。

无头全绿不等于起得来。最后一步真启动一次，用这几把尺子替代肉眼：

| 脚本（都在 `bwp-assets/`） | 一句话 |
| --- | --- |
| `check-pet-window.ps1` | 列桌宠进程所有顶层窗口：SFML 那扇在不在、可不可见、多大在哪。**这把尺自己不是 DPI-aware**（桌宠是 PerMonitorV2），所以量到的宽高坐标是逻辑像素，200% 缩放下就是物理值的一半，对得上就行 |
| `check-bubble-window.ps1` | 专看台词气泡那扇起没起、是不是画布尺寸、露多久收多久。这把**自己声明成 DPI-aware**，量到的是物理像素 |
| `click-at.ps1 -X .. -Y .. [-Button Right]` | 把真光标放到某个物理像素点上按一下（落点差超过 2 px 就不点）。**会挪你的鼠标，自己确认再跑** |
| `probe-jitter.ps1 -Seconds 120` | 摆位跳动的量尺：哪一扇、跳几次、Δx Δy、起手多大在哪，全是物理像素 |
| `hitmap.ps1` / `pet-hitmap.ps1` | 前者算预设小窗 13 个打靶点的屏幕绝对坐标；后者逐格摸宠物剪影上哪一格点得着（形心就是「右键点这里才开得出小窗」那个坐标） |

`drive` / `voice` / `sweep` 是素材侧的三条（驱动一副骨架跑动画、查语音包句池、扫骨架清单出 census 表），日常不用。

## 仓库里有什么

| 路径 | 是什么 | 克隆下来 |

## 读代码前必知的三个坑

1. **`deskspine/` 是嵌套 git 仓库。** 多数搜索工具和 `git status` 只看一层，两边要**分别** `git log` / `git status` / 提交。
2. **编码不统一，直接编辑会写坏中文。** `deskspine/DeskSpine/src/Program.cs` 和 `ConfigForm.cs` 是 **GBK 无 BOM + CRLF**：用 UTF-8 读进来再写回去，所有中文注释和弹框文案会变成乱码，**而编译照样过**，坏样子只在运行时露出来。改它们只能按字节替换（`bwp-assets/out/gbk-view/apply.py`，锚点要求恰好命中一次）。其余文件是 UTF-8，但又分「带 BOM + CRLF / 带 BOM + LF / 无 BOM + LF」三家，**别顺手统一行尾**（会把 `git status` 刷出一片空 diff 的 M）。细节和逐文件的字节账在 `docs/交接报告.md` §3。
3. **对外的名字和内部的名字是两套，这是裁定的结果。** 对外是 `BwpDesktopPet` / 「百闻牌桌宠」；代码里的 C# 命名空间还是 `DeskSpine.*`、目录还是 `deskspine/`、配置目录还是 `%LOCALAPPDATA%\DeskSpine`、单实例 Mutex 名和注册表自启值名还是 `Program.cs` 里那个 `ProgramName = "DeskSpine"`。跟着界面名字把它们改掉，等于把用户已有的配置和已经设好的开机自启弄丢，还会让第二个实例起得来（两只桌宠叠在一块）。想动这一层之前先读 `docs/交接报告.md` 里改名那一轮。

- **release 附件这一轮按「发出去的就是一只百闻牌桌宠」重出，一条命令是 `python projects/_publish/package_release_zips.py`（现场读数，不是计划）**：建产物的那棵树 = 快照 B 的工作树 + 本机那份**未跟踪**的衍生件（`git ls-files --others --ignored` 里 `DeskSpine/res/` 那 25 个），脚本第一步钉「这棵树的 tree 哈希 == 开发 HEAD 的 tree」——相等才建（现读：`git -C ../_publish/bwp-desktop-pet-deskspine rev-parse 'HEAD^{tree}'` 和 `git -C deskspine rev-parse 'HEAD^{tree}'` 比，**锚是那句相等不是某个号** —— 快照每重导一次号就漂一次），所以推上去的代码和附件里跑的那个 exe 是同一棵树建出来的，前面的实测才带得过去。出来的两份：框架依赖 **13.4 MiB / 108 条目**、自包含 win-x64 **80.1 MiB / 567 条目**，各带一份《运行前先看.txt》。**两份都带着那四只**（`res/` 89 个文件 / 12.8 MiB），解压就有宠物，不再需要 `setup_pet.py` 灌名册。每份自验跑齐五件事：CRC 逐条过、`.pdb` **0 枚**（`DebugType=none -p:DebugSymbols=false`，那两条参数不能省 —— 第一版附件就是因为默认 portable pdb 把建盘机器的整条目录写进产物，12 处本机路径就是这么带出去的，闸的 D 线现在盯着）、exe 里逐张比图标（**衍生那颗 6/6 张在场、上游占位那颗 0/6**）、按 `FindUsableSkel` 那条规则数四只都登记得上、**解回临时目录**用 `publish_gate.py --walk` 扫容器里的字节。最后再把 `desk` 判据和首启探针跑在这份产物上（`DESK OK` + 「回 4 只」）。
- **「解压就能用」这半句还欠肉眼。** 首启登记那条链子在附件的真素材上跑绿了（临时目录里登记出 4 只、路径真在场、托盘四行是中文名），但**真双击一次看桌面上站没站人**这一步在这台机器上做不了：开发版和附件那份共用同名 Mutex 和同一个配置目录，只能同时跑一个，而本机那位桌宠正在跑（不许我杀你的进程）；更根本的是本机**已经有配置**，首启按裁定整份跳过、不会自己加那四只。要验就两步：托盘右键**退出**正在跑的那只 → 把 `%LOCALAPPDATA%\DeskSpine` 临时改个名（比如 `DeskSpine.off`）→ 双击附件里的 `BwpDesktopPet.exe`；看完想回开发环境就把目录名改回来。**这一条标 SKIP 等用户复验**，文档不替肉眼签字。
- **`deskspine/Setup/Setup.vdproj` 里的 `ARPHELPLINK` 和 `Manufacturer` 还指着上游**（`ww-rm/DeskSpine` / `ww-rm studio`）。对外那个仓库的网址现在**有了**（`github.com/Alacky-mo/bwp-desktop-pet-deskspine`），换它不需要再等谁 —— 只是这文件是 MSI 那条线上的，MSI 搁置之后就没人实测过改完能不能建；要动就连同 MSI 一起点头。
- **语音那条线是仓库主人明确搁置的。** 代码里那条路是通的：`TinyEngine/src/Speaker.cs` 在换动画时按骨架**旁边**的 `voice/_manifest.tsv` 认出这是哪个表情，抽那一组句池用 winmm 播一条，一轮播完才重洗；专注期间自动静音；语音包不在就完全静默。但只有不知火这一只接过，**而且既没有配置键也没有界面开关**（`Speaker.Enabled` 默认 `true`，装了语音包就会出声，设置窗里关不掉），桌面真出声这件事也还欠复验。那份 `_manifest.tsv` 带日语原文，所以现在也不入库 —— 克隆下来这一路本来就是静默的，要出声得自己把语音包和清单装到骨架旁边。**release 附件那份不是静默的**：语音包和清单已经摆在那副骨架旁边，解压首启登记上不知火就会出声（上面那句「没有开关」在这里才露出来：`Speaker.Enabled` 硬默认 `true`、没人往里写，设置窗里那页「语音设置」又是上游留的一张**空页** —— Designer 里 `tabPage_VoiceConfig.Controls` 一个控件都没挂）—— 所以《运行前先看.txt》里明写了「不想听就把 `res\spine\buzhihuo_1127\voice` 删掉」。补一颗真开关是欠着的，不是没做就是打算不做。
