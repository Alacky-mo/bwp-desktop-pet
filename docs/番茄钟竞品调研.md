## 2. 它们靠什么做到简洁好用 → 在我们 276 px 纯点击面板里成立吗

|---|---|---|
| 首屏只有一个动作 | Tomighty（一扇小窗 + 大数字 + Start）、`pom`（一条命令） | **成立**，头顶浮窗已是这形态 |
| 用选项吃掉「输入」 | `pom` 的 pick length、Samaya 的 25/5/20 默认 | **成立**，三档已是此路线 |

## 3. 桌宠 / 游戏化这一类：多做对了什么、翻车在哪

**查证到的绑定规则**

- **TamoStudy**：币按专注分钟以固定速率发，用来买食物和装修；**闲置的日子会持续掉状态**；
  只有 "Peaceful" 难度允许暂停 —— 它把**惩罚强度做成显式的难度选择**，这点很干净。
  但宠物是**第二层**，仪表盘仍以倒计时、商城、图表为主。
- **rivet**（最贴我们形态的）：猫的表情随阶段变，README 明说「只要当天专注够久就保持开心」；
  可导航仍靠托盘图标、媒体键和设置面板。**1★、无 License**，只读思路。
- **Focus Dog**：规则最工程化 —— 零食机只在 5~120 分钟区间工作，**休息时机器停摆**，
  狗越来越饿、心情下降**但永远不会死**（无死亡结局）。
- **Study Bunny**：不间断学习才自动攒币，长时间挂机**扣币**，"Honesty Mode" 只记录不强制。
- **Forest**：离屏即枯；多人房间一人跑掉则**全组的树永久消失**；Flora 甚至能自报罚金（纯自觉）。
- **Finch**：反过来 —— 专注模块藏在设置菜单里，**鸟不受任何惩罚**，作者刻意不把它当番茄钟。

**成熟项目里没有一个把宠物做成唯一 UI**：TamoStudy 自陈是次要层，rivet 也留着托盘和设置面板。
（这条要和我们自己的现场对照：桌宠的表情已经跟着 `TransitionId` 换，那是**出口**，不是**输入面**。）

**差评集中在四点**（措辞出自 Focus Dog 自家榜单，方向打折，但和 Forest 社区长期抱怨一致）：
① 纯数字计数器改不了行为；② **惩罚过重赶跑人**（死树、罚金、多人连坐是典型）；
③ **养成系统变成第二个工作台账**（Focus Dog 被点名「图鉴、赛季、排位叠太密，会压垮轻度用户」）；
④ 广告与留存钩子侵入（Study Bunny 免费版有广告、$14.99 去广告；Forest 免费档含广告；
移动与桌面端更新节奏脱节）。

> 对照我们自己：**头像框接进桌宠、用户当天看实物就撤**（见 `docs/理解地图.md`），
> 达摩**只当图标不当宠物装饰**（2026-10-29 裁定）。这是同方向的现场证据，
> 但它佐证的是「别往宠物身上叠东西」，不能当成「竞品都不这么做」的证据。

## 4. 化用我们自己解包的素材（无圆环素材，这是硬事实）

竞品的主视觉几乎都是**矢量环**（SVG `stroke-dasharray` 或 SwiftUI `Circle().trim()`），
因为它们**没有位图字体/成套 sprite 的限制**，也不用对齐 180/255 的深底对比线。
我们**没有圆环素材**（`img_44_yuanquan` 只有 35x36，放大就糊），所以环这条路**放弃**，改走竞品自己的另一条主流：
**分段点 / 矩形进度条**——Focus To-do、番茄ToDo、Be Focused、极简番茄钟都用 4 枚分段点或横向细条。

下面每条都用 `docs/番茄钟界面方案.md` §3.2 里已量的数，不估：

1. **「本轮第几段/共几段」用 4 枚实心点，零新画**
   点亮态 = `bg_kuang01`（奶白实心圆角板 22x22、亮度 182/峰α 255、inset=2 能拉伸）；
   未点亮态 = `bg_kuang03`（深灰细线方框 32x32、亮度 41/峰α 179 —— **深底隐形，但小窗的底是
   `bg_tips_3` 浅色纸纹 222，所以「只能叠在浅色面板上」这条限制在小窗内正好成立**）。
   像素账：4×22 + 3×8 缝 = **112 px**，摘要行现在宽 248 → 放得下，且不用改面板宽。
   想两态同尺寸就都画成 22（`bg_kuang03` 按原图 1:1 贴会到 24 线宽上限，判据 §3.4 第 5 条盯的就是这个）。
2. **剩余时间**：4 枚暖色数字 + 冒号 ≈ **60~70 px 宽、22 px 高**即可读（现成 `FocusArt.DigitStrip`，
   缺任何一个字整行退系统字体那条规则不动）。段名两字（专注/短休/长假）24~40 px 足够。
3. **段名切换不靠图标，靠底板**：Pomotroid 用颜色区分段类型和暂停态；我们把数字条底下的板换色或换板即可
   （`FocusArt.RoundedBox` + `BackColour`，朱红 `#d82848` 系，§3.3 的实测配色）。
   「要保的语义优先于好看的造型」这条也用在 × 上：`com_btn_close`(143/255) 够亮，`com_btn_close2` 红叉更适合「停止专注」。
4. **红达摩气泡当「事件」不当「状态」**：只在换段时弹一次（对应 Forest 那种一次性可视后果），
   持续性信息全交给浮窗和表情。**别拿气泡当进度条用**。
5. **减号要从加号里裁**：`img_add`（加号 64x64、亮度 210/峰α 255，深底浅底都看得见）是**现成的**；
   **库里没有减号**（已裁好的 53 张里没有，`focus_ui_labels.tsv` 只有 `gui_ui_common_img_add 加号＋`）。
   把 `img_add` 横那一道切出来就是减号 —— 同一只手、同宽、同色；GDI 画线会画出和加号粗细不一致的一横。
6. **进度条若要做**：`bg_kuang02`（空心圆角框 28x28、拉得开、inset=4、角 3px 不涨）当轨道，
   `bg_tips_3` 裁一条按百分比缩的填充；或者用不可拉伸的 `com_btn_*` **整枚平铺成 N 格「吃掉的番茄」**，
   等分比环更好实现且不需新画。**反例**：`bg_diwen`（满幅花纹、平坦率 48%）不能拉伸，别拿它当条。
7. **常驻语义**（§2 那条最该补的）：托盘图标现在不表达「哪一段 + 暂停」。
   竞品靠动态 arc / 菜单栏文字；我们的通路是 `ShellNotifyIcon` 换 Icon —— 现成件是达摩 8 张 + 加号 +
   单选点，可以「专注=达摩正脸 / 休息=闭眼那一张 / 暂停=压暗」三态。**要做就得先出 8 张达摩的 .ico 变体**
   （`bwp-assets/png_to_ico.py` 已存在），并且**换段时才换**（`TransitionId`），不要每秒重设。

## 5. 该抄 / 不做 / 一条推翻我先前说法的诚实话

**该抄三条**

1. **Pomotroid 的常驻语义**：段类型 + 暂停态要能在「不看面板」时认出来。
   落地 = 托盘 tooltip 写「短休 04:59 / 已暂停」+（可选）托盘图标三态；宠物表情仍只在 `TransitionId` 换。
2. **Catime 的「不加输入框也能改时长」**：这**印证了你已经拍板的那条** —— 细项进小窗、纯点击 −/＋ 是对的形态。
   同时抄 YAPA 的「自动开始做成显式开关」：见下面第 4 条，我们现在这条是**写死的**。
3. **滴答清单式建议文案 + Pomotroid compact mode**：档位标签从「25/5/15/4」这种数，
   改成一行短字（「每 4 段后长休，建议 15~30 分」）；细项收在**同一扇窗的二级**，不开新窗。

**明确不做三条**

1. **任务列表 / 项目分组**：Pomofocus 用它换来「免费只存 3 个模板」的付费墙和 Todoist 集成；
   我们零后端，一加任务就变成 Focus Dog 被骂的那种「第二个工作台账」。
2. **图表统计（52 周热力图那种）**：Pomotroid 能做是因为 Electron + 本地历史 + 图表库；
   我们最多给「今天完成 N 段」这一句整数，气泡里已经有了。
3. **屏蔽网站/应用/锁机**：Forest、Be Focused、Session、Flow 都把它锁在 premium 里，说明它是**付费功能不是核心**；
   在 Windows 上做屏蔽会越界，还和桌宠的人格冲突。

**诚实话（这条推翻我先前口头转述的结论）**

我之前说过「调研支持四个分钟数彻底不给编辑，只留档位」。**报告里的证据指向相反方向**：
凡是有一定用户量的，全部开放逐分钟或至少逐 5 分钟编辑 —— Pomotroid（时长 + 轮数全可自定义）、
TomatoBar（工作/休息可配）、FocusTimer（可配长度）、YAPA（可配 periods）、
Catime（点 dock 直接改）、pomodorotimer.online 与 Pomofocus（三数可调）。
**只给档位的都是极小的**：Samaya 是 5★ 的只读镜像、`pom` 140★、Focus Dog 的数据来自自家宣传页。
**Samaya 的 25/5/20 是默认值，不是唯一选项。没有任何一个竞品把「三档预设」当成唯一的编辑面。**

⇒ 结论：**你的原裁定站得住**（细项进小窗、纯点击 −/＋），不用改方向。
要改的是两件小事：**(a) 别把细项做成唯一入口**（三档仍当首屏，一次点击就能开跑）；
**(b) 加输入速度补丁**，因为纯点击从 25 走到 45 要按 20 下 —— 这是 −/＋ 唯一的真实代价。

**现场核实的一条**（不是竞品结论，是我们自己的代码）：`TinyEngine/src/Pomodoro.cs:205-222` 的 `Advance`
把 Working→短/长休→Working **无限连轴**，只有 `Abort` 能停 ——
「自动开始下一段」在我们这里是**写死的默认且唯一行为**，不是开关（竞品把它做成开关）。
要不要给用户一个「做完一个番茄就停住等我点」的选项，这条得你定；它同时牵动小窗主按钮在休息段该写什么。

## 6. 摆法推荐（纯点击 / 无键盘 / 276 px / 数字是贴图）

报告给了三种竞品用过的形态，各自代价：

1. **步进器 −/＋**（Catime 的点击改值 + YAPA 的数值表单混合）：语义直白、不需模式切换、贴图只要 0~9。
   代价：**从 25 到 45 要按 20 下**。
2. **档位胶囊轮盘**（`pom` 的 pick length、Samaya 的默认值）：一次到位。
   代价：**四数联动会组合爆炸**，实际退化成「三档 + ±5」，用户失去「我要 37 分」的自由。
3. **长按连发 + 双击归位**（无直接竞品，是 Catime 交互的补丁版）：单点 ±1，约 400 ms 后每 120 ms ±1，
   双击回默认。代价：`NOACTIVATE` 窗口的 pressed 帧要自己画，**且没有可发现性**。

**推荐组合**：**2 当首屏入口 + 1 当细项 + 3 当速度补丁**。
即：首屏仍是三档（一次点击就开跑），点开「细项」才出现 4 行 −/＋，细项里再加长按连发。
